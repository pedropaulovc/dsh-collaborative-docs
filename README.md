# DSH Collaborative Docs

Local rich-text documents with comment threads for human–agent collaboration in DeepSeek Harness.

The editor uses BlockNote and Yjs. Humans and agents work against one shared document model; Markdown is an import/export format rather than the authoritative state. Agent edits must check the document revision before changing content.

Development is in progress. Installation and verification instructions will be added with the working integration.
